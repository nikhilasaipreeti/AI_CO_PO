# Upload Endpoints 📁

## POST /upload-marks
**Student Marks Upload**

**Content-Type**: multipart/form-data

**File**: Excel with Marks sheet (StudentID, Q1, Q2...)

## POST /upload-syllabus
**Course Syllabus**

**Input**: Text file or string with course description

## POST /upload-questions
**Question Paper**

**Input**: Scanned PDF or text questions

Auto-parsed and mapped by AI engine.
