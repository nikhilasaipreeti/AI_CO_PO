# Installation Guide 🛠️

## Prerequisites
- Node.js 18+
- Python 3.10+
- Git

## Clone & Setup
```
git clone <repo>
cd AI_CO_PO
```

## Backend (Node)
```
cd backend
npm install
node app.js
```

## Analytics Engine
```
cd analytics-engine
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
pip install fastapi uvicorn
```

## Frontend
```
cd frontend
# Open index.html
```

All ports: 3000 (backend), 8001 (analytics)
