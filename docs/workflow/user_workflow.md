# User Workflow 👥

## Faculty Experience

1. **Login** to dashboard (frontend/login.html)
2. **Upload Syllabus** → AI generates COs instantly
3. **Upload Question Paper** → Auto-mapped to COs/Bloom
4. **Enter Student Marks** → Excel upload
5. **View Results**:
   - CO/PO/PSO attainments + levels
   - Student performance charts
   - Coverage gaps
6. **Export Report** → NBA/NAAC format

```
Time saved: 80% | Accuracy: 95% | Effort: Minimal
```

No technical expertise needed.
