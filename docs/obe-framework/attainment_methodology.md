# Attainment Methodology ⚖️

## CO Attainment Formula
```
CO% = (Σ Student scores in mapped questions / max possible) / total students
```

**Threshold Check**: 60% students score ≥60% → CO attained

## Levels
| Level | Percentage |
|-------|------------|
| L3 | ≥70% |
| L2 | 60-69% |
| L1 | 50-59% |
| L0 | <50% |

## PO/PSO
```
PO% = Average of all mapped CO attainments
```

## Analytics Features
- Student clustering (KMeans)
- Coverage gaps (COs without questions)
- Bloom performance per level

Implemented in analytics-engine/services/.
