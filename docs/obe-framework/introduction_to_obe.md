# Introduction to OBE 📚

## What is Outcome Based Education?

**OBE** shifts focus from **what is taught** to **what students learn**:

```
Traditional → Teacher-centric
OBE → Student outcomes → Measurable results
```

## Key Elements
- **Course Outcomes (CO)**: What student achieves per course
- **Program Outcomes (PO)**: Graduate attributes (12 POs per NBA)
- **Program Specific Outcomes (PSO)**: Institution-specific
- **Attainment**: % achievement measured direct (exams) + indirect

## Why OBE?
- NBA/NAAC accreditation requires
- Industry-aligned skills
- Continuous improvement cycle

Our system **automates measurement** for all levels.
