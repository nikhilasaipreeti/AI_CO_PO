# Bloom's Taxonomy 🧠

## Cognitive Levels (Low to High)

| Level | Action Verbs | Example Question |
|-------|--------------|------------------|
| 1. Remember | List, Define | What is TCP? |
| 2. Understand | Explain, Describe | Explain TCP 3-way handshake |
| 3. Apply | Use, Implement | Implement ping utility |
| 4. Analyze | Compare, Classify | Compare TCP vs UDP |
| 5. Evaluate | Judge, Critique | Which protocol for video streaming? |
| 6. Create | Design, Develop | Design reliable file transfer protocol |

## Why Bloom in OBE?
- **Higher Order Thinking**: NBA emphasizes Analyze+ levels
- **Assessment Quality**: Ensures exam questions test deep understanding
- **AI Classification**: System auto-detects Bloom level per question
